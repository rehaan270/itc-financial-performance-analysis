# ITC Ltd. – Financial Performance Analysis

## 📊 Project Overview

A three-year financial performance analysis of ITC Ltd. based on its consolidated financial statements.

The project evaluates the company's financial performance using revenue and profit trends, year-on-year growth and key financial ratios.

## 🎯 Objectives

- Analyze ITC Ltd.'s financial performance over three years
- Study revenue and profitability trends
- Calculate and interpret key financial ratios
- Evaluate liquidity and solvency
- Identify important financial trends
- Present findings through Excel-based analysis and visualization

## 🔍 Areas of Analysis

- Revenue & Profit Analysis
- Year-on-Year Growth
- Profitability Ratios
- Liquidity Ratios
- Solvency Ratios
- Financial Trend Analysis
- Excel-Based Visualization

## 🛠️ Tools Used

- Microsoft Excel
- Financial Statement Analysis
- Financial Ratio Analysis
- Data Analysis
- Data Visualization

## 📁 Project Files

The repository will contain:

- Financial Statements
- Financial Analysis
- Ratio Analysis
- Excel Dashboard
- Project Report
- Sources & References

## 📌 Methodology

1. Collect consolidated financial statement data.
2. Organize the data in Excel.
3. Calculate year-on-year growth.
4. Calculate relevant financial ratios.
5. Analyze financial trends.
6. Create visualizations and dashboards.
7. Summarize the findings and conclusions.

## 🎓 Key Learning Outcomes

This project provides practical experience in financial statement analysis, ratio analysis, Excel-based data analysis and financial interpretation.
